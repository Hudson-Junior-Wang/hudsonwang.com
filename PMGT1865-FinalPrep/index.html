Q3 · PERT

A small project with three activities: A precedes B and C. Time estimates (a / m / b):

ActivityPredecessoramb
A–359
BA4610
CA248

1) te for each activity; 2) s for each activity; 3) total expected duration Te; 4) total standard deviation S; 5) Z for completing in 14 days (two decimals); 6) probability (two decimals, using the normal table in the slides).

展开详解（先自己做）
  1. te = (a + 4m + b) ÷ 6；s = (b − a) ÷ 6。A：(3 + 20 + 9)/6 = 32/6 = 5.33；B：(4 + 24 + 10)/6 = 38/6 = 6.33；C：(2 + 16 + 8)/6 = 26/6 = 4.33。s 全部 = 6/6 = 1.00，s² = 1。
  2. 用 te 找关键路径：A→B = 5.33 + 6.33 = 11.67；A→C = 5.33 + 4.33 = 9.67 → 关键路径 A-B（C 不计入）。
  3. Te = 关键路径上 Σte = 11.67 days；S = √(s_A² + s_B²) = √2 = 1.41 days（先加方差再开方，不是 1 + 1 = 2）。
  4. z = (目标 − Te) ÷ S = (14 − 11.67) ÷ 1.41 = 1.65 → 查表 P = Φ(1.65) = 95.05%。
答案（标准口径）：te 5.33 / 6.33 / 4.33；s 1.00 / 1.00 / 1.00；Te = 11.67；S = 1.41；Z = 1.65；Probability = 95.05%。

口径提醒：样卷官方解答把 te 取整（5 / 6 / 4），得到 Te = 11，Z = (14 − 11) ÷ 1.41 = 2.13，P = 98.34%。讲义没有统一取整规则——考场上先按公式原值算到底，旁边注明“取整口径：Te = 11，P = 98.34%”；最好考前问助教。

易错：把三个活动的 te 全加（15.99）；S = s_A + s_B = 2；z 写成 (Te − 目标) ÷ S 得负数；用 a、m、b 而不是 te 找关键路径。99% 扩展：Ts = Te + 2.33 × S ≈ 14.96 天。

Q4 · Resource Estimation

A welding task requires joining 150 m of seam. Standard productivity is 2.5 m/hour per welder; an efficiency factor of 0.85 applies. Quality control causes 5% rework (apply to total seam length). Crew: Days 1–4: 2 welders; from Day 5: a third welder joins. 8-hour workday; labour rate $80/hour per welder.

1) Total person-hours; 2) project duration in working days; 3) total labour cost.

展开详解（先自己做）
  1. 调整工程量 = 150 × (1 + 5%) = 157.5 m（返工率加在全长上）。
  2. 有效生产率 = 2.5 × 0.85 = 2.125 m / 人时。
  3. 总人时 = 157.5 ÷ 2.125 = 74.1176 ≈ 74.12 person-hours。
  4. 工期：Day 1–4：2 人 × 8 h × 4 天 = 64 人时 → 产出 64 × 2.125 = 136 m（未完成）；剩余 157.5 − 136 = 21.5 m → 21.5 ÷ 2.125 = 10.12 人时；3 人一起做：10.12 ÷ 3 = 3.37 h；工期 = 4 + 3.37 ÷ 8 = 4.42 days（整工作日 ≈ 5 天）。
  5. 成本 = 人时 × 费率 = 74.1176 × $80 = $5,929.41（用未取整人时；先取 74.12 再乘会得 $5,929.60）。
答案：74.12 person-hours；4.42 days（≈ 5 个工作日）；$5,929.41。

口径提醒：样卷按实际人时计费。若题目要求第 5 天三人按整天计薪，则成本 = (64 + 24) × $80 = $7,040——看题目说法。

易错：把人时当天数（74 天）；效率因子乘反（2.5 ÷ 0.85）；返工只加在剩余部分；Day 5 起仍按 2 人算。

Q6 · Cash Flow Analysis

Calculate the cash flow balance at the end of each month (project budget $60,000).

Month 1Month 2Month 3
Incoming funds$20,000$10,000$5,000
Planned expenses$15,000$25,000$10,000
展开详解（先自己做）
  1. 期末余额 = 期初余额 + 本期流入 − 本期流出；第 1 月期初 = 0（题目没给初始资金）。
  2. M1：0 + 20,000 − 15,000 = 5,000。
  3. M2：5,000 + 10,000 − 25,000 = −10,000。
  4. M3：−10,000 + 5,000 − 10,000 = −15,000。
答案：End M1 = $5,000；End M2 = −$10,000；End M3 = −$15,000。

解读：M2 起为负 → funding gap（资金缺口），需提前融资或调整收款时间。“预算够”不等于“现金够”——$60,000 预算不参与计算。

易错：把预算 $60,000 当期初现金；每月只算当月流入 − 流出而不滚动累计。

Q7 · Earned Value Management

BAC = $100,000. After the first quarter: PV = $30,000; EV = $25,000; AC = $28,000.

a) CV; b) SV; c) CPI; d) SPI; e) EAC assuming future performance is consistent with past performance (integer); f) status: ____ budget, ____ schedule.

展开详解（先自己做）
指标公式代入结果解读
CVEV − AC25,000 − 28,000−3,000over budget
SVEV − PV25,000 − 30,000−5,000behind schedule（单位是钱）
CPIEV ÷ AC25,000 ÷ 28,0000.89（0.8929）每花 $1 换回 $0.89 的工作
SPIEV ÷ PV25,000 ÷ 30,0000.83（0.8333）完成的工作只有计划的 83%
EACBAC ÷ CPI100,000 ÷ 0.8929112,000按现有效率预计超支 $12,000

口径提醒：样卷解答用取整后的 CPI 0.89 → EAC = 100,000 ÷ 0.89 = $112,360；用精确 CPI（= 100,000 × 28,000 ÷ 25,000）得 $112,000。考场两者都写并注明口径。若题干改成“剩余工作按计划完成”：EAC = AC + (BAC − EV) = 28,000 + 75,000 = $103,000。

易错：CPI 写成 AC ÷ EV；EAC = BAC × CPI；SV 的单位写成“天”；CV、SV 用 AC − EV 导致符号反。
