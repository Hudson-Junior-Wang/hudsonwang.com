Data channel

This page is a static file. To keep scores and the class list across devices it writes small JSON records into an issue of your own GitHub repository — your domain, your data, no third-party platform in the middle.

  1. Repository Hudson-Junior-Wang/hudsonwang.com must have Issues enabled. The page only posts comments; it never touches code.
  2. Create a fine-grained token at github.com/settings/personal-access-tokens/new — Only select repositories → this repo, permission Issues: Read and write, short expiry.
  3. Paste it below and press Save and test. The token stays in this device's localStorage and is only ever sent to api.github.com.
  4. Students need nothing: the leaderboard is publicly readable, so their scores show up as soon as they finish a run.
