0–6 MIN定义、动机、分析和网络

1 · Stakeholder 与分析流程 W1–3 · 老师Q01–09

  • Stakeholder（——一定要有合同或头衔吗？）：can affect or is affected；包括没有正式权力的受影响群体。
  • Engagement 强调双向交流和参与，不是只发通知；management 不应被简单理解为操控他人。
  • Identification → Assessment → Prioritisation → Engagement
  • Identify = 找谁；Assess = 动机、能力、贡献和影响；Prioritise = 现在重点关注谁。全程迭代，不是一次性名单。
  • Disaggregation：拆开“政府/社区”等大类，看 roles、contributions、aims & approach。

2 · Motivation 三种解释 W2 · Q04–06

理论抓哪个词
Classical self-interest自身利益（Smith）
Logic of consequentiality预期后果（March & Heath）
TPB（Ajzen）Attitude + Subjective norms + PBC → Intention → Behaviour

TPB（——赞成就一定做得到吗？）：Attitude = 对行为的评价；Subjective norms = 感到别人期待我做；PBC = 感到自己能做到。意图不保证行为，感知能力也不等于真实能力。

Financial incentive 不是TPB三项核心构成。Bounded rationality = 信息/时间/能力有限；full rationality = 完整信息下求最优。

3 · 不要把分析工具混在一起 W3、W6

工具看什么
Power–Interest影响力 × 关注程度
Potential matrixhelp 与 harm 两种能力，可同时很高
Commitment matrixcurrent 与 required commitment 的差距
SaliencePower、Legitimacy、Urgency

CATWOE：Customers（受益/受害者）、Actors（执行）、Transformation（转化）、Worldview（意义）、Owner（可叫停）、Environment（约束）。
MoSCoW：Must / Should / Could / Won’t have this time，不是永远不做。

4 · Salience 与 Bourne W6 · Q21–24

Salience 按有哪几个属性分类：

P：DormantL：DiscretionaryU：Demanding
P+L：DominantP+U：DangerousL+U：Dependent
P+L+U：Definitive；三个都无：Non-stakeholder

Bourne：Identify → Prioritise → Visualise → Engage → Monitor

Circle：径向深度 = power；外圈弧长 = influence；颜色 = 方向。橙 up、绿 down、紫 sideways、蓝 outwards。Budget 不是 P/L/U。

Q21 “influence and engagement level”不够精确，记 P/L/U。Q24 A、C 都是Budget，原题无法唯一判分。

5 · SNA 关键词匹配 W6、8 · Q25–29

  • Social network = actors + relations，不等于社交媒体或地理距离。
  • Ego = 研究的中心；Alter = 相连者；Tie = 关系线；multiplex = 多种关系。
  • Egocentric = 以一人为中心；Sociocentric = 有边界的整体网络；Adjacency matrix = 谁与谁连接的表，方向可能不对称。
  • Degree = 直接连接数；Betweenness = 他人最短路径经过它的程度。
  • Network层：density / centralisation；Actor层：centrality；Tie层：strength / direction / content。

无向 Density：D=tN(N−1)2。6个人最多15条边，实际6条 → 0.4。

6 · Rowley：两条轴一定分清 W8 · Q30–31

Centrality 低Centrality 高
Density 高SubordinateCompromiser
Density 低SolitarianCommander

Commander：自己连接关键、别人互不连接 → 掌握通路。Compromiser：自己和别人都连接紧密 → 需要协商。

Weak ties 传递新信息；strong ties 有助解决复杂问题。ACME：Power–Interest 的 Monitor 也可能是网络中的 Commander；正式地位不等于结构影响力。

6–18 MIN会议全过程：顺序、用途、动作

7 · Facilitation + 准备 W4–5 · Q10–20

Facilitation（——结果是谁的？）：structured process，让结果由参与者 created, understood, accepted。主持人负责过程，不强加内容。重要问题、答案不明显、需要 buy-in 时适用。

  • Type A 直接问概念；Type B 用熟悉情境和画面启动思考：“Think about the last time…”；更个人化。
  • Could = 发散；Should = 应做但未承诺；Must = 必要事项；Will = 承诺行动。Reacting questions：ask, don’t tell。
  • Energizing = 激发参与；Managing dysfunction = 处理干扰；Building consensus = 形成共识；Questioning = 建设性提问。Clairvoyant 察觉疲劳/脱离信号。

5 Ps：Purpose → Product → Participants → Probable issues → Process（最后）

3 Hs：Hands 有形产出、Heads 理解、Hearts 态度承诺。Topics 必要议题；Ditches 棘手难题；Red herrings 无关干扰。Sponsor 不要第1–3个发言。

8 · Starting：IEEI W9 · Q32–38

阶段一句话识别
Inform为什么开、要产出什么
Excite对你有什么好处，为什么值得投入
Empower你有什么重要角色和权限
Involve现在请你表达目标、问题

Excite 最重要也最有挑战性；说明你很重要 ≠ 已让你参与。

8步：Welcome → Purpose & product → Participants’ objectives → Agenda → Ground rules → Parking boards → Introductions（第7） → 首个议程项。把个人目标连到议程；漏项与小组商量处理。

ELMO = 发起投票，不是自动结束。Question first = 先问再反对。XYZ = 问题 → 后果/理由 → 期望行为。Parking：Issues / Decisions / Actions（Action、Who、When）。

9 · Focusing：Checkpoint 与 PeDeQs W10 · Q39–46

Checkpoint：Review → Preview → Big view

已完成什么 → 接下来做什么 → 为什么有助总目标。Big view = Excite，省略会让人质疑该环节。

PeDeQs：Purpose → Example → Directions → Exceptions → Questions → Starting question

Example 可用无关内容的简单类比；Directions 讲步骤；Starting question 真正启动思考，不能替代说明。

  • Label 标主题；Prompt “What else?” / “What other steps…?”；Redirect 征求同意后拉回。
  • Breakout：do, divide, direct（先全组做一个，统一理解，再分组）；每组3–7人；说清交付物、质量、流程、时限。
  • Warm-up：先问两道举手/点头回应的 pre-questions。

10 · Recording：Power of the Pen W11 · Q47–52

Write first, discuss second · Write what they said · Write so they can read it · Ask, don’t tell

  • 不等完美才记，不先求全组批准，不擅自“优化”发言人的话。
  • 保留原话维护 ownership、empowerment，降低主持人曲解风险；不保证绝无误解。
  • 记录四类：Decisions、Actions、Outstanding issues、Relevant analysis/comments，不是主持人个人偏好。
  • 简洁用 noun–verb–object、headline（须保留原意）；边写边重复/追问，避免 lulls；可安排 scribe。

“先解释、改进再写”“只记主持人认为好的”是滥用 pen，不是效率提升。

11 · Information gathering W12 · Q53–60

功能识别点
Gathering facts可核查、“right answers”；ask, record, react
Categorising逐项问 Same or different?
Inquiring预先分组写问题（pre-questioning），改善Q&A
Generating ideasbrainstorming：ask, record, don’t react
PrioritisingImpact、Probability of success、Cost-effectiveness
Reportingprimary commenters：优点 → 如何改进 → 其他组补充
Getting feedbackstrengths：round-robin；ways to improve：random；举手看支持程度

投票前可 lobbying；a score is not a decision，打分后仍查共识。Popularity 不是上述最低标准。

12 · Closing：把结果变成行动 W13 · Q61–65

Review → Define → Evaluate → End → Debrief

回顾活动/个人目标/parking boards → 定义可沟通内容 → 评价价值与结果 → 提醒下一步并正式结束 → 与 sponsor 复盘。

  • Consensus（——一定是每个人最喜欢吗？）：“I can live with it and will support it”。Polling the jury 逐人问，有顾虑问可接受的最小改动。
  • Issues：覆盖了吗 → 需要覆盖吗 → 现在需要吗；需要但不现在 → Actions。
  • Actions 只交给在场的人，期限由本人定；负责确保完成，不必亲自包办。
  • 沟通：Simple list（可沟通）、Dual list（可/不可沟通）、Matrix（Audience、Information、Who、Vehicle、When）。

18–23 MIN范围补漏 + 高频易混

W7 · Self-awareness 不能因老师65题没问就跳过

  • Intent–impact gap：我想表达的 ≠ 对方实际感受到的。成长链：self-examination → insight → self-understanding → changed behaviour；洞见不是终点。
  • Sensitive line：自我概念受挑战时变防御 → threat–rigidity。反馈 verifiable、predictable、controllable 时较不易越线。
  • 三大维度：self-understanding & self-management；sensitive line；尊重个体差异。五个方面：Values、Interpersonal style、EI、Attitude towards change、Cognitive style。
  • Goleman EI四域：Self-awareness、Self-management、Empathy、Skilled relationship；可以通过持续练习发展，不是固定天赋。不能用性别/文化平均值判断个体。
  • Locus of control：internal 看自己行动；external 看外力。Ladder of inference：观察 → 选择数据 → 加意义 → 假设 → 结论 → 信念 → 行动；别把推断当事实。

选项含 only / always 并不自动错误。例如“本课动作只分配给在场者”恰是课程规则。先读清 NOT / EXCEPT / all that apply，再用框架判断。
