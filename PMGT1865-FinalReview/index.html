最常考的框架 · 考前速记 点击折叠 / 展开
  • W1Freeman 对 stakeholder 的定义是 can affect / is affected。分析流程是 identify → assess → prioritise → engage。Disaggregation 要看三样：roles、contributions、aims & approach。
  • W2TPB 中 attitude、subjective norms、PBC 共同决定 intention，intention 决定 behaviour。Bounded rationality 和 full rationality 要能区分。
  • W3CATWOE 六项是 Customers、Actors、Transformation、Worldview、Owner、Environment。MoSCoW 是 Must、Should、Could、Won't。Potential matrix 看 help 与 harm，commitment matrix 看 current 与 required 的差距。
  • W5准备顺序是 5 Ps：Purpose → Product → Participants → Probable issues → Process。3 Hs 是 Hands（产出）、Heads（理解）、Hearts（态度）。Probable issues 分 topics、ditches、red herrings。Sponsor 不要第 1–3 个发言。
  • W6Salience 三个属性是 power、legitimacy、urgency。只有 power 是 Dormant；有 power 和 urgency、没有 legitimacy 是 Dangerous；有 legitimacy 和 urgency、没有 power 是 Dependent；三个都有是 Definitive。
    Bourne 五步是 identify → prioritise → visualise → engage → monitor。
    无向网络 density = t ÷ [N(N−1)/2]。
  • W7Brouwer 链条是 examination → insight → understanding → behaviour。Sensitive line 被越过会引发 threat–rigidity 反应。Self-awareness 五维是 values、interpersonal style、EI、attitude to change、cognitive style。
  • W8Rowley 矩阵中：高 centrality + 低 density = Commander；高 centrality + 高 density = Compromiser。
    低 centrality + 高 density = Subordinate；低 centrality + 低 density = Solitarian。
    Weak ties 带来新信息，strong ties 用来解决复杂问题。
  • W9Opening 共 8 步，introductions 排第 7 步。IEEI 四步：Inform、Excite（最难）、Empower、Involve。ELMO 是触发投票，不是一个人就能叫停讨论。XYZ 的三部分是问题、后果、期望行为。
  • W10Checkpoint 包括 review、preview、big view，其中 big view 相当于 Excite。PeDeQs 六步：Purpose、Example、Directions、Exceptions、Questions、Starting question。
  • W11使用 pen 的规则是 write first, discuss second、记录原话、写得让大家看得清、ask don't tell。
  • W12Gathering facts 要 react，brainstorming 不要 react。打完分不等于做了决定（a score is not a decision）。Strengths 用 round-robin 收集，improvements 按随机顺序收集。
  • W13Closing 五步是 Review → Define → Evaluate → End → Debrief。Consensus 的定义是 "I can live with it and will support it"。Actions 只分配给在场的人，完成日期由本人定。
