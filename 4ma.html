数据通道 data channel

这一页是纯静态的：要把「谁的报名 / 谁的投票」存下来并让全班刷新可见，需要一条你自己控制的写入通道。这里用的是你自己 GitHub 仓库的 Issues——域名是你自己的，没有第三方平台在中间。

  1. 确保仓库 Hudson-Junior-Wang/hudsonwang.com 的 Issues 是打开的（本页只往里面发评论，不会碰代码）。
  2. 去 GitHub 生成一个 fine-grained token：
    github.com/settings/personal-access-tokens/new
    勾选 Only select repositories → 选这个仓库；权限只给 Issues: Read and write；有效期设短一点（例如 30 天）。
  3. 把 token 粘到下面，点「保存并测试」。token 只存在你这台设备的 localStorage，只会发往 api.github.com。
  4. 学生端不需要 token：他们扫码打开链接，刷新就能看到最新结果。
